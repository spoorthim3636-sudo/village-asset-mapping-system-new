About Our Project

Village Asset Mapping System is a GIS-based web application developed to identify, locate and manage important village assets. It provides a digital platform to visualize schools, hospitals, water tanks, roads and other public facilities through an interactive map. The system helps improve village resource management and provides easy access to geographical information.
